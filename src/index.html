Middle-Earth Maps: LoTR interactive map

A Google Maps-inspired Middle-Earth interactive web app

With this interactive map you can learn about J.R.R Tolkien's Middle-Earth. The map focuses on The Third Age both on canon and non-canon places and events from all media from Lord of the Rings such as videogames
